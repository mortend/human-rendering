# Appendix B. Diagram plates

The following plates are deliberately text-native. They are complete teaching diagrams now and can later serve as briefs for commissioned vector illustrations without changing the argument.

<section class="diagram-plate">

## Plate 1. The human rendering pipeline

```text
WORLD / TEAM / BODY
        |
        v
  [ PERCEPTION ] ---- Se / Si
        |
        v
  [ POSSIBILITY ] --- Ne / Ni
        |
        v
  [ EVALUATION ] ---- Ti / Te / Fi / Fe
        |
        v
  [ ACTION ] -------- behavior / artifact / message
        |
        +------------ feedback ------------+
```

_Caption:_ Cognition is recursive. Output alters the scene that the next perception must render.

</section>

## Plate 2. Two perceptual axes

```text
                       ABSTRACT
                          |
              Ne          |          Ni
          many futures    |    converging future
                          |
EXTERNAL -----------------+----------------- INTERNAL
                          |
              Se          |          Si
         present field    |    remembered field
                          |
                       CONCRETE
```

_Caption:_ The diagram is a model of attentional preference, not a map of neural anatomy.

</section>

## Plate 3. Two judgment axes

```text
                       IMPERSONAL
                          |
              Te          |          Ti
       external result    |    internal coherence
                          |
EXTERNAL -----------------+----------------- INTERNAL
                          |
              Fe          |          Fi
       shared relation    |    personal value
                          |
                        VALUE
```

_Caption:_ Thinking and feeling both evaluate; they differ in the criteria they privilege.

</section>

<section class="diagram-plate">

## Plate 4. The four corrective pairs

```text
Se  <============================>  Ni
evidence                         trajectory

Si  <============================>  Ne
continuity                       possibility

Ti  <============================>  Fe
coherence                        relationship

Te  <============================>  Fi
effectiveness                    conscience
```

_Caption:_ Development is not replacing a preference; it is allowing an excluded signal to correct it.

</section>

<section class="diagram-plate">

## Plate 5. Dominant, auxiliary, tertiary, inferior

```text
      DOMINANT        default renderer
          |
      AUXILIARY       stabilizing counterweight
          |
      TERTIARY        familiar workshop / relief
          |
      INFERIOR        vulnerability + development gate
```

_Caption:_ Stack position describes a dynamic relationship, not a percentage of mental capacity.

</section>

<section class="diagram-plate">

## Plate 6. Explore and exploit

```text
              EXPLORE
       generate / search / vary
          /               \
         /                 \
   uncertainty           options
         \                 /
          \               /
       select / build / measure
              EXPLOIT
```

_Caption:_ Creative production depends on the transition between opening and closing, not permanent residence in either.

</section>

## Plate 7. The salience budget

```text
incoming signals
||||||||||||||||||||||||||||||||||||
       [ GOALS ] [ FEAR ] [ REWARD ] [ NOVELTY ]
                       |
                       v
              PRIORITY / ATTENTION
                       |
                  limited budget
```

_Caption:_ What wins attention is not necessarily what is most important; it is what the current system has learned to prioritize.

</section>

<section class="diagram-plate">

## Plate 8. Prediction and correction

```text
 MODEL ---> EXPECTATION ---> SAMPLE ---> ERROR
   ^                                    |
   |                                    v
   +------------ UPDATE <---------- WEIGHT

 healthy: error can revise model
 captured: model explains error away
```

_Caption:_ A useful model needs a feedback channel through which it can lose.

</section>

<section class="diagram-plate">

## Plate 9. Social reality testing

```text
             PRIVATE MODEL
             /     |     \
            /      |      \
      ARTIFACT   RECORD   OTHER PERSON
            \      |      /
             \     |     /
              SHARED CHECK
```

_Caption:_ No single witness is infallible. Shared reality becomes stronger through independent channels.

</section>

<section class="diagram-plate">

## Plate 10. Adversarial rendering

```text
 urgency ----+
 isolation --+--> narrowed input --> forced model --> compliance
 repetition -+
 reward -----+

 countermeasures:
 time + records + alternatives + outside contact + reversible choice
```

_Caption:_ Manipulation reduces another person's ability to inspect and revise the model being imposed.

</section>

<section class="diagram-plate">

## Plate 11. Team attractors

```text
                 curiosity
                    ( )
                     |
 blame ( ) ---- current state ---- ( ) craft
                     |
                  crisis
                    ( )

 repeated transitions deepen the easiest path
```

_Caption:_ Culture is partly the set of states a group enters easily and the transitions it finds difficult.

</section>

<section class="diagram-plate">

## Plate 12. Conflict translation

```text
 POSITION        TRANSLATION          TEST

 "too risky" -> protection need -> bounded prototype
 "too slow"  -> execution need  -> decision deadline
 "feels wrong" -> value signal  -> visible criteria
 "not heard" -> relation signal -> explicit feedback path
```

_Caption:_ Translate identity claims into needs, thresholds, and reversible experiments.

</section>

<section class="diagram-plate">

## Plate 13. The production review loop

```text
 CAPTURE -> HISTORY -> OPTIONS -> MODEL
    ^                             |
    |                             v
 FEEDBACK <- BUILD <- DECIDE <- VALUES
```

_Caption:_ A review is complete when the artifact, prior learning, alternatives, mechanism, values, decision, and feedback all have a place.

</section>

<section class="diagram-plate">

## Plate 14. Function currencies

```text
 Se: immediacy       Si: continuity
 Ne: optionality     Ni: direction
 Ti: clarity         Te: throughput
 Fi: integrity       Fe: legitimacy

       exchange requires translation
```

_Caption:_ Teams fail when one currency is treated as the only form of value.

</section>

<section class="diagram-plate">

## Plate 15. Stress narrows the renderer

```text
 WIDE FIELD                 NARROW FIELD

 evidence  options             threat
 history   values      --->    urgency
 people    future              certainty

 recovery restores channels before it restores elegance
```

_Caption:_ Under pressure, improve sleep, safety, time, and information quality before demanding sophisticated integration.

</section>

<section class="diagram-plate">

## Plate 16. Psychological safety

```text
 SIGNAL -> SPEAK -> RECEIVE -> EXAMINE -> RESPOND -> LEARN
             x
             |
      humiliation / exclusion

 a broken speak-receive link hides defects until cost grows
```

_Caption:_ Safety is the reliability of the correction channel, not the absence of standards or discomfort.

</section>

<section class="diagram-plate">

## Plate 17. The center and the boundary

```text
            .-----------------.
          .'    many states     '.
         /   fear  play  grief    \
        |       .---------.        |
        |       | CENTER  |        |
        |       | can move|        |
         \      '---------'       /
          '.                   .'
            '-----------------'
```

_Caption:_ The center is not one preferred state. It is the capacity to remain organized while states change.

</section>

<section class="diagram-plate">

## Plate 18. The geometry of return

```text
 signal -> attention -> meaning -> action
    ^                                |
    |                                v
 context <- revision <- feedback <- result

 return is repetition with information
```

_Caption:_ Integration is visible when feedback changes the next pass through the system.

</section>
