# 14. The complete function-interaction atlas

This atlas describes all 64 directed function interactions among the eight cognitive functions. Read the row as **lead function → receiving function**. Direction matters: Se offering evidence to Ni is different from Ni asking Se to test a trajectory. These are collaboration prompts, not predictions of chemistry or compatibility.

Every interaction has four layers: what the lead contributes, what the receiver may misread, how to translate, and where the pair appears in graphics production.

| **Ne**   | A concrete anomaly opens alternatives               | Se sees distraction; Ne sees premature closure | Anchor brainstorming to one reproduction case; generate hypotheses for a rendering artifact.  |
| **Ni**   | Present data tests a future model                   | Se sees abstraction; Ni sees isolated detail   | Ask which observation would change the forecast; test the architecture in a vertical slice.   |
| **Ti**   | Direct behavior becomes a mechanism question        | Se sees delay; Ti sees uncontrolled variables  | Preserve the capture, then reduce it; turn a GPU glitch into a minimal reproduction.          |
| **Te**   | Evidence triggers execution and triage              | Se sees bureaucracy; Te sees unowned action    | State symptom, cost, owner, and next measurement; use a timing capture to select work.        |
| **Fi**   | Immediate experience checks personal value          | Se sees subjectivity; Fi sees surface pressure | Show the artifact and ask what must remain emotionally true; compare quality degradations.    |
| **Fe**   | Visible behavior informs group coordination         | Se sees social delay; Fe sees unframed impact  | Demonstrate without blame; use a shared review where the artifact, not a person, is examined. |

## Reading the matrix in practice

Use the atlas diagnostically, not typologically. Identify the operation currently leading and the operation that cannot enter. Then find the directional row and test its translation. The same two people may occupy different sides of the relationship in another task.

```text
name the lead signal -> identify the excluded receiver -> translate -> test -> review
```
