# The Human Rendering Pipeline: MBTI Physics for Graphics Programmers

> A PDF book and publishing pipeline connecting MBTI cognitive functions, social dynamics, and graphics programming practice.

An independent book and PDF generator about cognitive functions, social dynamics, and graphics engineering.

The Human Rendering Pipeline treats MBTI cognitive functions as a practical interpretive language for graphics programmers and technical teams. It connects attention, prediction, memory, values, decision-making, communication, and conflict with render graphs, profiling, shader work, production constraints, and team collaboration. The book is designed as a field guide: concrete enough to use in a graphics review, careful enough not to turn type patterns into diagnoses, job requirements, or fixed identities.

## Build

```sh
npm run build
```

The build requires Node.js, Pandoc, WeasyPrint, uv, Poppler, and Ghostscript. veraPDF is used for independent PDF/UA validation.
